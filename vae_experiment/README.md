# VocalArticulationEnvelope — Experimental Specification v1.1, steps 1–8

Offline implementation of `VAE_Experiment_Spec_v1_1.md`, which is the controlling
document. Where this README and the spec disagree, the spec wins.

**Authorized scope: steps 1–8 only.** Step 9 (reversal-existence gate) is not
crossed. Step 10 (statistical lock) is outstanding — **no statistical analysis
code exists in this repository**, deliberately: §13 is provisional until step 10
selects the estimation form and outcome coding, and freezing it early is a §14
Void condition. No human data is collected or prepared.

## Running

Generated audio fixtures (F1, F3, and the F2 stand-in) are not committed — they
are deterministic functions of their generators. Regenerate them first; the
committed F9 goldens then verify the regenerated set, which checks the generators
as well as the pipeline.

```bash
pip install -r requirements.txt
python3 tools/bootstrap.py          # regenerate F1, F3, F2_SYNTH, F8 ground truth
python3 tools/steps.py all          # steps 1, 2, 3, 4+5, 6, 7, 8 -> reports/
python3 tools/steps.py 1 --write-goldens   # regenerate F9 after a code change
python3 -m pytest tests -q
python3 tools/exercise.py           # steps 6-8 against SYNTHETIC_TEST_ONLY tables
```

Fixture generators (`tools/make_f1.py`, `make_f3.py`, `make_f2_synth.py`,
`make_synthetic_oracle.py`) are deterministic: regenerating reproduces the same
bytes.

## Implementation decisions

Places where the spec is terse and a choice had to be made. Each is
deterministic, carries no learned parameter, and is logged.

1. **Onset time refinement** (`hear.py`). A spectral-flux peak localises a
   transient only to its 2048-sample window, a bias of up to 46 ms that the
   5.8 ms F1 gate would not survive. The onset is refined to the 10 % point of
   the energy rise — the same 10 % point §4's attack-sharpness definition uses —
   searched inside the interval the flux definition pins the transient to, and
   found by backtracking from the local peak so a modulated baseline cannot pin
   it to the window start.
2. **Tempo** (`hear.py`). ODF autocorrelation read as a harmonic comb over a fine
   period grid inside 70–140 BPM. Still a single global estimate from the ODF
   autocorrelation; the comb reads the same ACF at `h·T` so period resolution is
   not capped by the 5.805 ms frame lag.
3. **Beat phase** (`hear.py`). §4's objective exactly. It is piecewise-constant in
   phase, so ties within `epsilon_num` break on the smaller salience-weighted
   squared residual, then the smaller phase.
4. **Audible pulse** (`hear.py`). §2's "audible percussive or clearly articulated
   pulse" is operationalised as a pulse being both *present* (grid-match rate)
   and *articulated* (onset density no greater than the eighth lattice can hold).
   Grid-match rate alone is satisfied by dense texture.
5. **`LEAD_IN` and `PHRASE_TAIL` uncertainty** (`shape.py`). Neither has a second
   measured endpoint, so the shrinkage term uses the one real anchor's sigma with
   the configured endpoint contributing zero.
6. **`C_FLAT` constants** (`conditions.py`). The fixed uniform grid uses
   `I_reference` and `SIGMA_GRID_ONLY` from the versioned config — already-fixed
   constants, and not clip-derived, which is the control's whole point.
7. **`C_SHUFFLED` donor** (`conditions.py`). The lexicographically next `audio_id`
   among slot-count-matched clips, wrapping. Deterministic, no RNG.
8. **Cross-word resyllabification is not performed** (`lexicon.py`). It is not
   specified, and it would make a line's syllable boundaries depend on its
   neighbours, which §11's position-for-position matching cannot tolerate.
9. **R1 whole-beat guard tolerance** (`oracle.py`). A real one-beat phase slip
   lands *near* the beat period, never on it, so the guard compares with one
   analysis hop of slack. Slack in this direction is the safe one: R1 excludes
   rather than corrects.

## Not built

Nothing on the §19 DO NOT BUILD list. In particular: no downbeat identification,
no pitch/f0, no chord transcription, no source separation, no neural G2P, no
neural MIR, no LM generation, no persistence beyond flat files, and — per the
step-10 gate — no statistical analysis code.
